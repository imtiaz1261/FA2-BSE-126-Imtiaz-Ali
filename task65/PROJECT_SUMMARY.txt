WHY GRAPHRAG WINS
─────────────────────────────────────────────────────────────────────────────

Problem with Vector RAG:
  ❌ Finds documents based on semantic similarity
  ❌ Cannot follow explicit entity relationships
  ❌ Returns random relevant text (high false positives)
  ❌ Fails completely on multi-hop questions

Solution (GraphRAG):
  ✅ Stores explicit relationships as graph edges
  ✅ Traverses edges to find exact answers
  ✅ Returns ONLY logically connected entities
  ✅ Solves multi-hop questions through graph traversal

Example:
  Question: "Who is John Smith's manager's manager?"
  
  Vector RAG:
    → Searches for "manager manager John Smith"
    → Finds random docs mentioning managers
    → Returns wrong person or "not found"
  
  GraphRAG:
    → John Smith → [MANAGED_BY] → Sarah Johnson
    → Sarah Johnson → [MANAGED_BY] → Michael Chen
    → Returns: Michael Chen (exact answer via graph edges)
