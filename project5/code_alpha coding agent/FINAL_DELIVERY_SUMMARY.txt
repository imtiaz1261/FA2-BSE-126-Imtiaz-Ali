================================================================================
                         TROUBLESHOOTING GUIDE
================================================================================

ISSUE: Ctrl+Shift+K not working
SOLUTION:
  - Make sure VS Code is focused
  - Try: Ctrl+Shift+P → Search "Code Alpha" → Select option
  - Or reload: Ctrl+Shift+P → Reload Window

ISSUE: Backend not responding
SOLUTION:
  - Check: http://localhost:8000/health in browser
  - If not running: python kiro_backend/app.py
  - Wait 3 seconds for startup

ISSUE: No code appears after execute
SOLUTION:
  - Wait 2-3 seconds
  - Check browser console: Ctrl+Shift+I
  - Try simpler task: "hello world"
  - Check backend console for errors

ISSUE: Extension won't load
SOLUTION:
  - Run: cd kiro_interface && npm run build
  - Reload VS Code
  - Check .vscode/extensions.json

ISSUE: Port 8000 in use
SOLUTION:
  - Kill process: taskkill /PID [pid] /F
  - Or use different port in app.py
