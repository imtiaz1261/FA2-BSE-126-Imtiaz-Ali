API ENDPOINTS
════════════════════════════════════════════════════════════════════════════

1. GET /
   Root information endpoint
   
2. GET /health
   Health check - indicates server is running
   
3. POST /tasks
   Create a new coding task
   Request: { "prompt": "...", "repo_path": "..." }
   Response: { "task_id": "...", "status": "pending" }
   
4. GET /tasks
   List all tasks
   
5. GET /tasks/{task_id}
   Get task status and details
   
6. GET /tasks/{task_id}/stream
   Stream real-time events (Server-Sent Events)
   Events: log, progress, code, complete
   
7. POST /tasks/{task_id}/approve
   Approve task changes

Interactive API documentation available at:
  http://localhost:8000/docs (Swagger UI)
