════════════════════════════════════════════════════════════════════════════════
                       TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

ISSUE: Interface doesn't appear
SOLUTION:
  1. Make sure VS Code is focused (click window)
  2. Try Ctrl+Shift+K again
  3. Try Ctrl+Shift+P → "Code Alpha" → select option
  4. Or reload: Ctrl+Shift+P → Reload Window

ISSUE: Sub-tasks don't update
SOLUTION:
  1. Wait 1 second
  2. Check browser console: Ctrl+Shift+I
  3. Look for errors
  4. Restart backend

ISSUE: Code not showing
SOLUTION:
  1. Click "Code" tab
  2. Wait 2-3 seconds
  3. Check console for errors

ISSUE: File not created
SOLUTION:
  1. Check Explorer: Ctrl+Shift+E
  2. Should show task_XXXXX_*.py files
  3. Check workspace folder is open
  4. Try refreshing: F5

ISSUE: Backend error
SOLUTION:
  1. Check: http://localhost:8000/health
  2. Should return 200
  3. If not: Restart backend
  4. Kill: taskkill /F /IM python.exe
  5. Restart: python app.py
