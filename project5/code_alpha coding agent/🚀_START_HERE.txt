TERMINAL 1 - START BACKEND:
   cd kiro_backend
   pip install fastapi uvicorn pydantic
   python app.py

   Expected: "Uvicorn running on http://0.0.0.0:8000"

TERMINAL 2 - BUILD & LAUNCH EXTENSION:
   cd kiro_interface
   npm install
   npm run build
   code .

Then press Ctrl+Shift+K to open the interface.

  http://localhost:8000/docs

• Create Task:
  POST http://localhost:8000/tasks
  { "prompt": "your task here" }

• Get Task Status:
  GET http://localhost:8000/tasks/{task_id}

• Stream Events (SSE):
  GET http://localhost:8000/tasks/{task_id}/stream

ISSUE: Backend won't start
   → Check Python installed: python --version
   → Install deps: pip install fastapi uvicorn pydantic
   → Port 8000 in use: change port in app.py

ISSUE: Extension doesn't appear
   → Run: npm run build (in kiro_interface/)
   → Reload VS Code: Ctrl+Shift+P → "Reload Window"

ISSUE: Webview blank
   → Verify backend: http://localhost:8000/health
   → Check DevTools: Ctrl+Shift+I

ISSUE: No code generation
   → Ensure input not empty
   → Check backend terminal for errors
   → Verify temp directory writable
