════════════════════════════════════════════════════════════════════════════
TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════

ISSUE: Kiro interface doesn't appear
  SOLUTION: Make sure you pressed Ctrl+Shift+K
  OR: Check if extension was built (run: npm run build in kiro_interface/)

ISSUE: Interface is blank/white
  SOLUTION: Check if backend is running
  Open: http://localhost:8000/health in browser

ISSUE: No code appears after clicking EXECUTE
  SOLUTION: Look at browser console (Ctrl+Shift+I)
  Check backend terminal for error messages

ISSUE: Task input not working
  SOLUTION: Click in textarea first
  Make sure text area has focus (cursor visible)

ISSUE: Backend crashes
  SOLUTION: Kill process on port 8000
  Command: taskkill /PID <pid> /F
  Restart: run START_KIRO_COMPLETE.bat again
