════════════════════════════════════════════════════════════════════════════════
                        IF SOMETHING GOES WRONG
════════════════════════════════════════════════════════════════════════════════

ISSUE: Interface doesn't appear
FIX:
  1. Ctrl+Shift+K again
  2. Or Ctrl+Shift+P → search "Code Alpha"
  3. Or reload: Ctrl+Shift+P → Reload Window

ISSUE: Nothing happens when clicking EXECUTE
FIX:
  1. Check backend: http://localhost:8000/health
  2. Should see {"status":"healthy"}
  3. If not, backend stopped - restart it

ISSUE: Code not showing
FIX:
  1. Click "Code" tab
  2. Wait 2-3 seconds
  3. Check console: Ctrl+Shift+I

ISSUE: File not created
FIX:
  1. Check workspace folder is open
  2. Look in Explorer (Ctrl+Shift+E)
  3. Files should be there
