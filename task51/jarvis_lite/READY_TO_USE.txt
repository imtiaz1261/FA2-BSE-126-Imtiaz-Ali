🔧 TROUBLESHOOTING QUICK FIXES
================================================================================

❌ "No microphone detected"
   → Check Windows: Settings > Sound > Microphone enabled

❌ "No audio output / audio won't play"
   → Enable browser autoplay: Settings > Autoplay > Allow Audio
   → Check system volume: Should be 50%+

❌ "Voice input not recognized"
   → Speak clearly and slowly
   → Check microphone is not muted
   → Try again or ask for text instead

❌ "App shows error on startup"
   → Check terminal for error message
   → Kill process: Get-Process streamlit | Stop-Process -Force
   → Restart: streamlit run streamlit_app.py --server.port 8501

❌ "Something not working?"
   → See VOICE_VERIFICATION.md for complete troubleshooting
   → Check terminal logs for error details
