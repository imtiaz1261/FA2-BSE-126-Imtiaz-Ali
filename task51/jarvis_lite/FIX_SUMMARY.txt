================================================================================
TROUBLESHOOTING
================================================================================

ISSUE: "No microphone detected"
  → Check Windows sound settings
  → Verify microphone is connected and enabled
  → Run: python -m speech_recognition

ISSUE: "No TTS backend available"
  → Reinstall: pip install pyttsx3 gtts
  → Restart app: Ctrl+C then streamlit run streamlit_app.py --server.port 8501

ISSUE: "Audio won't play"
  → Enable browser autoplay: Settings → Autoplay → Allow audio
  → Check volume settings
  → Try manual playback with audio player

ISSUE: "Streamlit won't start"
  → Kill process: Get-Process streamlit | Stop-Process -Force
  → Check Python 3.9+: python --version
  → Reinstall deps: pip install -r requirements.txt --force-reinstall

Full troubleshooting guide: See VOICE_VERIFICATION.md
