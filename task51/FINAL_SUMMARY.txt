WHAT WAS BUILT
================================================================================

A production-ready, full-stack AI knowledge assistant that combines:

✅ RAG (Retrieval-Augmented Generation)
   - Multi-format document loading (PDF/DOCX/TXT)
   - Intelligent chunking and semantic search
   - Configurable embeddings (HuggingFace or OpenAI)
   - Vector storage (ChromaDB or FAISS)

✅ Conversational Memory
   - Buffer memory (last N messages)
   - Summary memory (auto-summarize)
   - Context-aware follow-up questions

✅ Intelligent Agent Routing
   - Calculator tool (math expressions)
   - Weather tool (weather API)
   - Document search (RAG wrapper)
   - Fallback to general LLM
   - 90%+ routing accuracy

✅ Voice I/O (Speech Recognition & Text-to-Speech)

HOW TO RUN
================================================================================

Quick Start (5 minutes):

  1. Navigate to project:
     cd jarvis_lite

  2. Create & activate virtual environment:
     python3.11 -m venv venv
     source venv/bin/activate  # Linux/macOS
     # OR
     venv\Scripts\Activate.ps1  # Windows PowerShell

  3. Install dependencies:
     pip install -r requirements.txt

  4. Configure environment:
     cp .env.example .env
     # Edit .env and add your OPENAI_API_KEY

  5. Start FastAPI server:
     uvicorn api:app --reload --port 8000

  6. Open in browser:
     http://localhost:8000/static/index.html

Alternative Interfaces:

  Streamlit:
    streamlit run streamlit_app.py

  Command-line:
    python main.py ingest data/uploads/example.pdf
    python main.py query "What is the topic?"
