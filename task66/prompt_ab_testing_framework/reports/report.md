# Prompt A/B Testing Report

## Objective
Compare two prompt variants using randomized assignment and data-driven statistical analysis.

## Prompt variants
### Variant A
Direct, friendly, concise assistant instructions.

### Variant B
Structured expert instructions emphasizing goal identification, constraints, correctness, actionability, completeness, and avoiding invented information.

## Experiment design
- Assignment: random 50/50 split
- Primary metric: task completion
- Secondary metrics: thumbs-up rate, response length, quality score
- Statistical test: two-sided chi-square
- Confidence interval: 95% CI for B minus A
- Significance threshold: p < 0.05

## Dataset
The ZIP contains 120 synthetic demo interactions generated by `app/generate_demo_data.py`.

**Academic integrity note:** these 120 records are synthetic and must not be presented as real-user interactions. For the actual assignment claim, run the application and collect real user interactions.

## Recommendation rule
Declare a winner only if its primary metric is higher and p < 0.05. Otherwise continue the experiment and collect more data.
